# Employee_Performance_-_Salary_Analytics
📊 An HR Analytics project using Python, Pandas, and NumPy to clean employee data, analyze salary and performance trends, and track departmental KPIs and attrition. Outcome: A cleaned dataset, Excel reports, top 10 performer rankings, and actionable insights for data-driven HR decisions.
📊 Employee Performance & Salary Analytics System

Transforming Employee Data into Actionable Business Insights

📌 Project Overview

The Employee Performance & Salary Analytics System is a Python-based HR analytics project designed to process, clean, transform, and analyze employee data. Using Pandas and NumPy, the project explores salary trends, employee performance, departmental KPIs, experience levels, and attrition patterns to generate meaningful business insights and structured Excel reports.

🎯 Project Objectives

Clean and validate employee datasets.

Identify missing values, duplicate records, and invalid data.

Analyze salary distribution and employee performance.

Evaluate department-wise KPIs and employee attrition.

Identify top-performing employees.

Automate data processing and Excel report generation.

Support data-driven HR decision-making.

🛠️ Tech Stack

Python — Data processing and analysis

Pandas — Data cleaning, transformation, and aggregation

NumPy — Numerical operations and missing-value handling

Microsoft Excel — Dataset management and reporting

CSV — Structured data storage

Matplotlib & Seaborn — Planned data visualization and dashboards

⚙️ Project Workflow

Data Loading: Import employee records from CSV and Excel files.

Data Inspection: Examine data structure, data types, and statistical summaries.

Data Cleaning: Handle duplicates, missing values, inconsistent department names, and invalid entries.

Data Transformation: Calculate annual salaries, experience levels, performance categories, salary bands, and years in the company.

Exploratory Data Analysis: Analyze salary trends, employee performance, departmental statistics, and attrition.

Report Generation: Export cleaned data, department summaries, and top-performing employee reports to Excel.

📈 Key Analysis Areas

Department-wise average salary and performance

Salary comparisons across job roles

Top 10 employee performance rankings

Experience and salary relationships

Employee attrition analysis
